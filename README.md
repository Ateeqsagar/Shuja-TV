# Shuja TV 1.1

Android TV IPTV player (Xtream Codes) - Live TV, Movies, Series, global search, settings.

Build: push to GitHub, run the "Build APK" workflow, download the Shuja-TV-apk artifact.
Or open in Android Studio and run Build > Build APK(s).


## Version 2 enhancements
- Fixed TV remote long-press action menu so it no longer activates the first menu item.
- Adaptive launcher icon for circular and square launchers.
- Search field explicitly opens the software keyboard on focus/click.
- Branded startup content-refresh screen with progress.
- Xtream Codes and remote M3U/M3U8 playlist login.
- Configurable seek interval: 5, 10, 15, 30, 60, 120 or 300 seconds.
- Provider thumbnails, category metadata and Xtream short EPG remain the authoritative sources. Missing artwork uses the app fallback rather than unlicensed scraping.
